# Синхронизация Mac и телефона

Mac — сервер, телефон — клиент. Обе стороны держат одинаковый журнал `events.jsonl` (append-only),
синхронизация — это объединение журналов по `id`: ничего не перезаписывается, конфликтов нет.

## Обнаружение

Mac объявляет себя через Bonjour: тип `_prokachka._tcp`, имя `Прокачка · <имя Mac>`,
TXT-запись `device=<id Mac>`. Телефон ищет этот тип через NSD и берёт IPv4-адрес и порт.

## Сопряжение

1. Mac показывает 6-значный код. Код живёт 5 минут и сгорает после 5 неверных попыток.
2. Телефон: `POST /pair`, тело — JSON без шифрования:
   `{"code":"123456","device":"phone-…","name":"Nothing Phone (1)"}`.
3. Mac отвечает `{"key":"<base64 32 байт>","device":"mac-…","name":"MacBook Air"}`.
   Ключ общий для всех устройств, создаётся при первом сопряжении.

Ключ передаётся открыто внутри локальной сети. Защищают его 6 цифр, короткое время жизни кода
и лимит попыток.

## Обмен

Все запросы ниже — `POST`, заголовок `X-Device: <id телефона>`, тело — AES-256-GCM:
`nonce (12 байт) ‖ шифротекст ‖ тег (16 байт)`, тот же формат, что `AES.GCM.SealedBox.combined`
в CryptoKit. Ответ зашифрован так же. Вектор для проверки обеих платформ: `vectors/sync.json`.

1. `POST /sync` `{"device":"…","ids":[все id телефона]}` →
   `{"events":[события Mac, которых нет у телефона],"need":[id телефона, которых нет у Mac]}`.
2. Если `need` не пуст: `POST /push` `{"device":"…","events":[запрошенные события]}` → `{"accepted":N}`.

Приняв события, сторона дописывает в журнал только новые `id` и сразу записывает награды за квесты,
которые закрылись благодаря чужим делам. У награды детерминированный `id` (`q-day-five-2026-11-01`),
поэтому если оба устройства закроют квест без связи, после слияния останется одна награда.

Ответы с ошибкой: `403` — устройство не подключено, `401` — ключ не подходит, `410` — код устарел.

## Когда

Телефон обменивается, пока приложение открыто: при открытии, каждые 20 секунд и через 0,7 секунды
после записи, правки или покупки. Mac принимает запросы, пока запущен (в том числе из строки меню).

## Дальше

Вне дома — ретранслятор на своём сервере: он хранит только зашифрованные события и не знает ключа.
